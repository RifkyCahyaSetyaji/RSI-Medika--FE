# SIBK Retina Diabetik - Frontend (CAD-ViT)

Frontend web application untuk Sistem Informasi Deteksi Retinopati Diabetik berbasis Vision Transformer (ViT).

## Tech Stack
- **Framework:** React 18 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Setup & Menjalankan Lokal

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3000` dan secara otomatis memproksi panggilan API (`/api` dan `/media`) ke backend di `http://127.0.0.1:8000`.

3. **Build untuk production:**
   ```bash
   npm run build
   ```
